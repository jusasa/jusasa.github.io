# 소켓에 할당되는 IP주소와 PORT 번호

## 인터넷 주소

인터넷 주소란?
- 인터넷 상에서 컴퓨터 구분목적으로 사용하는 주소
- 4B IPv4와 16B IPv6 존재
- 소켓 생성시 기본 프로토콜 지정
- 네트워크 주소/호스트 주소 나뉨
    - 네트워크 주소로 네크워크 찾고 호스트 주소로 호스트 구분

CLASS A,B,C 각각 네트워크 주소가 1B, 2B, 3B로 늘어나고 호스트는 반대

A 0~127 -> 첫 BIT는 항상 0

B 128~191 -> 첫 두 BITS는 항상 10

C 192~223 -> 첫 세 BITS는 항상 110

## 소켓 구분에 사용하는 PORT 번호

PORT 번호?
- IP는 컴 구분, PORT는 프로그램 구분 용도
- 하나의 프로그램은 둘 이상의 소켓 존재 O -> 둘 이상의 PORT가 하나의 프로그램에 의해 할당 O
- PORT 번호는 16bits로 표현, 따라서 값은 항상 0~65535
- 0~1023은 잘 알려진 PORT(Well-known PORT)라 해서 이미 용도가 결정되어 있음

# 주소 정보의 표현

## IPv4 기반 주소 표현을 위한 구조체

```C
struct sockaddr_in
{
    sa_family_t     sin_family;  // 주소체계
    uint16_t        sin_port;    // PORT 번호
    struct in_addr  sin_addr;    // 32비트 IP주소
    char            sin_zero[8]; // 사용되지 않음
};

struct in_addr
{
    in_addr_t       s_addr;      // 32비트 IPv4 인터넷 주소
};
```
