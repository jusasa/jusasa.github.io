## 웹 페이지간의 데이터 전송

서버를 통해서 웹에서 웹으로 데이터 전송

# Form 태그, request 객체

```HTML
<Form action="페이지" method="get/post">
    <!-- 입력 양식 -->

</Form>
```

- `get`방식: url에 데이터 담아서 전송, 주소창에 정보 보임 -> 보안에 취약, 정보 크기 1024바이트
    - 키워드: 보인다, 제한있다
- `post`방식: HTTP body에 담아서 전송, 주소창에 정보 안보임, 정보 안보임으로 보안성 유리, 정보의 크기 제한 없음
    - 키워드: 안보인다, 제한 없다

네임 속성에서 서버단에서 데이터 뽑아와야함

전달할때 변수와 값 둘 다 넘김

값은 무조건 String임

따라서 정수든 뭐든 숫자를 쓰려면 캐스팅 해야 함. 자바의 wapper 클래스 이용

```JAVA
int i = Integer.parseInt("1"); // "1" -> 1
```
