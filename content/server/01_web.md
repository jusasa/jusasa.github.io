## 정/동적 페이지

>두 구조의 차이, 흐름 설명

정적(static) 페이지

- 웹서버가 html 보내주면 렌더링 하고 끝

동적(dynamic) 페이지

- html 말고 jsp(기타등등) 파일 요청하면 jsp 컨테이너 실행(컴파일, 서블릿 적재)
- 중간 단게의 자바 파일을 컴파일 하는거임. jsp는 자바파일 x
- 처리 결과 전송 -> html

정적은 소개문이나 안내문등, 동적은 로그인, 게시판 등등임!!!!

요청마다 다른 페이지를 만든다는거임!!!!!!

웹브라우저에 html 해석기가 있음 = 인터프리터

가끔 해석 못함 = 벤더마다 약간씩 달라서

컴파일러 = 실행코드로 만듬 -> 다음에 실행 할때 실행코드만 실행하면 됨

인터프리터 = 실행할떄마다 해석기가 따라다녀야함 -> 실행할때마다 다시 해석함

자바는 컴파일, 인터프리터 특징을 모두 가지고 있음

## 서블릿==JSP 동작 원리

>서버 동작 프로그램과 컨테이너

- 서블릿: 웹 환경 요청을 서버에서 처리하기 위해 서버에서 동작하는 **자바 프로그램**

- 서블릿 컨테이너: 요청된 웹 문서에 대응되는 서블릿을 실행하고 그 결과를 html 문서로 응답

- JSP(java(jakarta) script page): 동적 페이지를 만들기 위한 서버쪽 스크립트-처음 실행될때 서블릿 컨테이너가 서블릿 클래스로 컴파일하여 실행

$\rightarrow$ JSP를 쓰면 컨테이너가 서블릿으로 바꿔 실행된다.

## JSP 실행 과정

jsp ---변환---> 자바 소스(서블릿) ---컴파일---> 클래스 파일 ---적재---> 메모리 적재, 실행(html)

변환, 컴파일은 처음 요청에 한번만!!!!


## 파일 구조

```text
프로젝트/
├─ src/main/java/              자바 소스 파일
└─ src/main/webapp/            웹 애플리케이션 루트
	├─ index.jsp                시작 페이지
	├─ css/                     스타일시트
	├─ js/                      자바스크립트
	├─ images/                  이미지
	└─ WEB-INF/                 외부에서 직접 접근할 수 없는 영역
		├─ web.xml               웹 애플리케이션 배포 서술자
		├─ views/                JSP 화면 파일
		├─ classes/              컴파일된 클래스 파일
		└─ lib/                  라이브러리 JAR 파일
```
