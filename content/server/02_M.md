# JSP 기본 구조

## 디렉티브와 스크립트릿

디렉티브: <%@> 로 시작하는 놈


페이지의 설정 정보를 지정

page 디렉티브 속성1
- **contentType**: JSP가 생성할 문서 타입 지정, 기본값:"text/html"
- autoFlush: 출력 버퍼 다 찼을때
- buffer
- errorPage
- isELIgnored
- **import**: 사용할 자바 라이브러리 지정, import="java.util.*"
- **language**: 스크립트릿 코드의 프로그래밍 언어 지정, "euc-kr", 기본값:"ISO-8851-1"
- **pageEncoding**
- session: 기본값:"true"
- isErrorPage: 이 페이지가 에러일시 보여지는 페이지인지 지정, 기본값="false"
- info

---

스크립트릿: 중간에 <%><%> 이거

형식
```JSP
<%
//코드1
//코드2
...
%>
```

문자열 출력
```JSP
<%
    out.println("ㅎㅇ"); // 브라우저에 찍힘(html, html 태그 가능)
%>

<% String str = "name"; %>
안녕 <%=str%>!
```
